## 🎨 Teevra Design System & Color Palette

The entire website UI has been re-architected following the exact design principles, dark obsidian aesthetic, and color tokens of **Teevra Studios (`teevra.co`)**:

| Token Name | Hex Code | Purpose |
| :--- | :--- | :--- |
| **Obsidian Dark** | `#080808` / `#0D0D0D` | Primary background, deep brutalist matte darks |
| **Surface Dark** | `#121212` / `#141414` | Card backgrounds and containers |
| **Elevated Surface** | `#181818` / `#1C1C1C` | Active pills, nested containers, and form inputs |
| **Signature Electric Lime** | `#AAFF00` (`#af0`) | Primary accent, CTA buttons, active state, glow shadows |
| **Neon Chartreuse** | `#EEF23A` | High-energy secondary tags and metrics |
| **Warm Peach Coral** | `#FFA670` | Secondary stage indicators and client badges |
| **Electric Blue** | `#638AFF` | Brand film accents and special tags |
| **Hairline Border** | `rgba(255, 255, 255, 0.1)` | Subtle studio dividers and card outlines |
| **Editorial Serif** | `Instrument Serif` | Italicized words inside headlines (*impossible*, *without limits*, etc.) |
| **Modern Sans** | `DM Sans` & `Inter` | Clean body copy, navigation, and technical data |
